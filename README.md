<h1 align="center">MedPrumo</h1>

<p align="center">
  Calculadoras, escores, medicamentos e CID-10 para consulta rápida no plantão.<br>

## Instalar

**iPhone (Safari)**
1. Abra o link no Safari
2. Compartilhar > Adicionar à Tela de Início
3. Confirme em Adicionar

**iPhone (Chrome)**
1. Abra o link no Chrome
2. Compartilhar (na barra de endereço) > Adicionar à Tela de Início
3. Confirme em Adicionar

**Android (Chrome)**
1. Abra o link no Chrome
2. Menu ⋮ > Instalar app
3. Confirme em Instalar

**Computador**
- Chrome ou Edge: abra o link e clique no ícone de instalar na barra de endereço
- Safari (Mac): abra o link e use Arquivo > Adicionar ao Dock
- Também funciona direto no navegador, sem instalar

**Offline:** abra uma vez com internet. Depois funciona sem conexão. As atualizações chegam sozinhas quando o app é aberto com internet.

## Funcionalidades

- **183 ferramentas** entre calculadoras e escores, organizadas em 24 especialidades
- **Medicamentos:** busca por princípio ativo ou marca, com apresentações, fabricantes, tarja e tipo de receita
- **CID-10:** busca por código ou termo, navegação por capítulos
- **Cronômetro:** modo simples, RCP e dinâmica uterina
- **Favoritos** para fixar as ferramentas mais usadas
- **Tema claro e escuro**
- **Funciona offline** depois da primeira abertura
